# Security Policy

## Supported Versions

Currently, only the latest `main` branch version of clsecure is supported with security updates. We recommend always keeping your local copy up to date.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Security is a core focus of clsecure. If you discover a security vulnerability, please do NOT report it by creating a public GitHub issue.

Instead, please send an email to clsecure@pablopda.com.ar or open a private security advisory on GitHub if available.

We will try to respond to vulnerabilities within 48 hours and work with you to patch the issue and release a fix promptly.
